Collexa

A College Community Web Application developed using the MERN Stack to manage clubs, events, announcements, and student activities through a centralized platform.

Features
- Admin Portal
- Club Coordinator Portal
- Student Portal
- Event & Club Management
- Announcements & News
- Role-Based Access Control
- Image Upload Support
- Dark Mode
- Responsive UI

Tech Stack

### Frontend
- React.js
- Tailwind CSS
- JavaScript
- Vite

 Backend
- Node.js
- Express.js

Database
- MongoDB
- Mongoose

Security
- bcrypt Password Hashing
